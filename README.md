# Digital-Sound-Processing-Project-MIR
The objective of this project is to practice with tools and methodologies on deriving descriptors of audio signals, and with fundamental machine learning (ML) classification algorithms. 
Using the FMA Dataset and the scikit and essentia libraries, I made a model that predicts the genre of a song, out of 4 possible ones.

## System Specifications

### Operating System
- **Windows 11** with **WSL2 (Windows Subsystem for Linux)**
- **Ubuntu 22.04** running in WSL2 environment

### Development Environment
- **Python**: 3.8
- **WSL**: Version 2
- **Terminal**: Windows PowerShell v5.1 / Ubuntu bash

### Required Python Libraries

pandas numpy matplotlib seaborn scikit-learn essentia librosa 

### Hardware Requirements
- **RAM**: Minimum 8GB (16GB recommended for large datasets)
- **Storage**: At least 10GB free space for FMA dataset
- **CPU**: Multi-core processor recommended for feature extraction

### Dataset
- **FMA (Free Music Archive)**: Small subset used
- **Size**: ~7GB compressed, ~8GB uncompressed
- **Format**: MP3 audio files with metadata CSV files
